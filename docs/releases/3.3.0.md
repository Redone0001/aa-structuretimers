# 3.3.0 — Theme and responsive controls

- Follow the active Alliance Auth theme using its Bootstrap CSS variables, including Darkly and Bootstrap Dark without relying on the legacy night-mode flag.
- Replace timer-list Select2 chips with compact searchable checkbox dropdowns. Select multiple values, see a selection count, and clear a filter without expanding the toolbar.
- Keep solar-system and structure-type autocomplete controls within their form as the window or sidebar changes size. Use standard themed selects for simple choices.
- Match form inputs, autocomplete results, date pickers, loading indicators, recon heatmaps, and campaign maps to the selected theme.
- Let filters wrap into a responsive grid while keeping each control a consistent height.

No database migration is required. Run collectstatic as part of the usual upgrade to refresh the changed CSS and JavaScript.

Validated against Alliance Auth 5.3.0 with Flatly, Darkly, Materia, Bootstrap, and Bootstrap Dark. Theme definitions: https://gitlab.com/allianceauth/allianceauth/-/tree/master/allianceauth/theme
