# 3.5.0 — Regional system map

- Add a standalone Regional map section beside Recon campaigns, using imported EVE SDE schematic positions and stargates.
- Combine relationship, preliminary/upcoming timer and geographic jump-range filters with AND logic. Range origins can be selected from any region.
- Show EVE structure icons with relationship frames, grouped timer counts and permission-filtered sidebar actions.
- Support pan, zoom, keyboard selection, spacing presets, layer toggles and responsive desktop/mobile layouts using Alliance Auth themes.
- Separate the reusable SVG renderer from the timer adapter and protect asynchronous updates from stale responses.

## Upgrade

Install this branch in the Alliance Auth virtual environment:

```sh
python -m pip install --upgrade "aa-structuretimers @ git+https://github.com/Redone0001/aa-structuretimers.git@map_view"
```

Enable `modeltranslation` first in `INSTALLED_APPS` and add `eve_sde` if they are not already enabled. Keep `structuretimers` enabled. Then, from the Auth project directory:

```sh
python manage.py migrate
python manage.py esde_load_sde
python manage.py collectstatic --noinput
python manage.py check
```

Restart the Auth web and Celery services using the installation's normal process. The initial SDE import can take time. No new Structure Timers migration is required, but the SDE dependency has its own database tables.

See [regional-map documentation](../regional-map.md) for the payload contract, setup, verification and limitations. Verified with 318 Django tests, three JavaScript suites and browser checks in AA 5.4.0 with Flatly, Darkly and Materia.
